## 🛡️ Featured project: AgentShield-X

Zero-trust security and governance for LLM, RAG and agent systems (deny by default).

- Scans text, retrieved documents, tool output and images; removes injected instructions and redacts secrets
- Authorizes every tool call against a registry, schema, roles, attribute rules and human approval
- Tamper-evident audit ledger with Ed25519 + ML-DSA-65 signed checkpoints
- Free AI assistant on the site: bring your own Groq or Gemini key, the model is auto-detected
- CI with CodeQL, gitleaks and Trivy; documented threat model and limits
